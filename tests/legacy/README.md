# Legacy ad-hoc test scripts

Manuelle Erkundungs- und Vergleichsskripte aus früheren Iterationen.
Sind **nicht** Teil der pytest-Suite und werden nicht automatisch ausgeführt.

Die offizielle Testsuite liegt unter [`backend/tests/`](../../backend/tests/).

Diese Skripte können bei Bedarf direkt ausgeführt werden, z. B.:

```powershell
python tests/legacy/test_quick.py
```
